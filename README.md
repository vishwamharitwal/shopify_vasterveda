## 🏛️ Theme Architecture & Tech Stack

- **Shopify Online Store 2.0 (OS 2.0)**: JSON-based modular templates (`templates/index.json`, `product.json`, `collection.json`, `cart.json`).
- **Motion & Micro-interactions**: GSAP 3 + ScrollTrigger for royal entrance animations, sticky reveals, and magnetic buttons.
- **Color Identity**:
  - Royal Deep Maroon / Velvet Crimson (`#580A15`, `#3A0207`)
  - Metallic Royal Gold Foil (`#D4AF37`, `#ECC880`)
  - Pale Ivory & Pure Silk White (`#FCFAF6`)
- **Typography**: `Cinzel` & `Cormorant Garamond` (Headings) + `Montserrat` (Body).
- **Features**:
  - Live Ajax Cart Drawer (`snippets/cart-drawer.liquid`)
  - Direct WhatsApp Concierge for Bespoke Bridal Sizing
  - Jharokha arched category cards
  - Jaipur Karigari authenticity badges

## 🚀 How to Connect to Shopify Store via GitHub

1. Push this folder to your GitHub Repository:
   ```bash
   git init
   git add .
   git commit -m "feat: initial VastrVeda royal theme commit"
   git branch -M main
   git remote add origin <your-github-repo-url>
   git push -u origin main
   ```

2. Go to **Shopify Admin** -> **Online Store** -> **Themes**.
3. Under **Theme Library**, click **Add theme** -> **Connect from GitHub**.
4. Select your repository and `main` branch.
5. Click **Connect**. Shopify will automatically sync all changes on every `git push`.
